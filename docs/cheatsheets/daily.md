# Повседневная работа — Dired, справка и оформление

## Файлы и каталоги
C-x d — открыть каталог в Dired. Nerd Icons Dired добавляет значки.
| Клавиши в Dired | Действие |
|---|---|
| RET | Открыть файл или каталог |
| ^ | Родительский каталог |
| g | Обновить |
| m / u | Отметить / снять отметку |
| U | Снять все отметки |
| C | Копировать отмеченные файлы |
| R | Переименовать или переместить |
| + | Создать каталог |
| q | Закрыть окно Dired |

D отмеченные файлы удаляет после подтверждения; используй осторожно. Упражнение: создай временный каталог вне рабочего репозитория, скопируй туда тестовый файл и переименуй его.

## Справка
Which-key: начни сочетание (например C-x или C-c) и подожди полсекунды. Helpful: C-h f — функция, C-h v — переменная, C-h k — фактическая привязка клавиши, C-h x — команда. C-g отменяет ввод. M-x my/open-cheatsheet или C-c h открывает наши памятки.

## Документация
Markdown Mode открывает .md и .markdown. TAB на заголовке — сворачивание, если доступно в контексте; M-x imenu — переход к заголовку. M-g i — Consult Imenu. C-c e расширяет выделение, C-c j переносит курсор по видимому тексту, C-c u/r — undo/redo (см. editing.md).

## Markdown Preview

Однократная установка на Debian (Node/npm из mise):

```sh
sudo apt install pandoc
mise use -g 'npm:@mermaid-js/mermaid-cli'
mmdc --version
```

- `C-c C-c p` — предпросмотр всего Markdown-документа в браузере через Pandoc с подсветкой кода.
- `C-c C-c l` — стандартный живой предпросмотр EWW внутри Emacs (ограниченное оформление).
- `C-c m` — предпросмотр отдельной Mermaid-диаграммы в буфере Emacs через markdown-mermaid. Поставь курсор внутрь fenced-блока mermaid; альтернативная команда `M-x markdown-mermaid-preview`.

Mermaid CLI использует Chromium/Puppeteer; при ошибке проверь буфер `*mermaid-error*` и наличие mmdc через `M-: (executable-find "mmdc")`. Рендеринг диаграммы локальный. Pandoc не рендерит Mermaid в полном HTML-документе; отдельная команда предназначена именно для диаграммы. Для конфиденциальных документов не используй внешние сервисы предпросмотра.

Собственный Python-сервер и локальная npm-зависимость удалены. Старые node_modules и package-lock.json, если они остались локально и относились только к предпросмотру, можно удалить.

## Внешний вид и автоматические функции
- Modus: M-x load-theme, например modus-vivendi. Перед переключением при необходимости отключи старую тему через M-x disable-theme.
- Doom Modeline: имя буфера, Git и другие индикаторы.
- Nerd Icons: если вместо значков квадраты, M-x nerd-icons-install-fonts и перезапуск.
- Savehist сохраняет историю minibuffer, Recentf — недавние файлы (M-x recentf-open-files).
- Save Place запоминает позицию курсора; Repeat Mode упрощает повтор поддерживаемых команд.
- Pixel Scroll Precision работает в GUI; Show Paren подсвечивает пары.
- Eat: M-x eat — терминал; не путай его с agent-shell. Команды shell вводятся в терминале, а запросы агенту — в агентном буфере.

Упражнение: открой памятку через C-c h, найди заголовок через M-g i, затем через C-h k выясни команду C-c j.
