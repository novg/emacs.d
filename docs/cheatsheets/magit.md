# Magit — памятка на каждый день

Для нашей конфигурации Emacs. Все короткие клавиши ниже относятся к буферам Magit, если не указано иначе. `C-` — Ctrl, `M-` — Alt, `RET` — Enter.

## 1. Главное окно

Открой файл рабочего проекта и нажми `C-x g` (`magit-status`).

| Клавиши | Действие |
|---|---|
| `C-x g` | Открыть Magit |
| `g` | Обновить состояние репозитория |
| `n` / `p` | Следующая / предыдущая секция |
| `TAB` | Раскрыть или свернуть секцию |
| `RET` | Открыть объект под курсором |
| `?` | Меню команд Magit |
| `q` | Закрыть текущее окно Magit |

Секции: **Untracked files** — новые файлы; **Unstaged changes** — неподготовленные изменения; **Staged changes** — изменения для следующего коммита.

## 2. Ветки

| Клавиши | Действие |
|---|---|
| `b` | Меню веток |
| `b b` | Переключиться на ветку или ревизию |
| `b c` | Создать ветку и переключиться на неё |
| `b r` | Переименовать ветку |
| `b k` | Удалить ветку |

Для новой задачи: переключись на `develop`, обнови её через меню `F`, затем `b c`. В ответ на запросы Magit укажи исходную ревизию `develop` и имя новой ветки, например `anovgorodskij/ALPAVI-1271`.

## 3. Ревью изменений агента

1. `C-x g`, затем `g` — обновить состояние.
2. Перейди к изменённому файлу в `Unstaged changes`.
3. `TAB` — раскрыть diff.
4. `RET` на строке diff — перейти к исходному файлу.
5. `s` — подготовить проверенное изменение к коммиту.

| Клавиши | Действие |
|---|---|
| `s` | Stage объекта под курсором (файл, блок diff, выделение) |
| `u` | Unstage — убрать из staging, сохранив изменение в файле |
| `S` | Подготовить все изменения отслеживаемых файлов |
| `U` | Убрать все изменения из staging |
| `d` | Меню diff |
| `k` | Удалить изменение (опасно!) |

**Важно:** `k` может уничтожить незакоммиченный код. Для снятия staging используй `u`, а не `k`. При ревью агента лучше использовать `s` по отдельным файлам или блокам вместо `S`.

## 4. Создание коммита

1. Подготовь нужные изменения через `s`.
2. Нажми `c c` — откроется буфер `COMMIT_EDITMSG`.
3. Напиши сообщение коммита в первой строке, например `ALPAVI-1271 Fix parameter import`.
4. Нажми `C-c C-c` — Magit сохранит сообщение и выполнит коммит.
5. Проверь статус и историю. Коммит пока локальный.

| Клавиши | Действие |
|---|---|
| `c c` | Начать создание коммита |
| `C-c C-c` | Подтвердить коммит в редакторе сообщения |
| `C-c C-k` | Отменить создание коммита |

Отдельно сохранять сообщение через `C-x C-s` не требуется. Строки комментариев Git, начинающиеся с `#`, обычно не входят в сообщение коммита.

## 5. Fetch, Pull, Push

Регистр букв важен.

| Клавиши | Действие |
|---|---|
| `f` | Меню Fetch |
| `f a` | Fetch всех remotes |
| `F` | Меню Pull |
| `F u` | Pull из upstream |
| `P` | Меню Push |
| `P u` | Push в upstream |
| `P p` | Push в push-remote |

При первом push новой ветки выбери нужный remote и проверь назначение. Если upstream ещё не настроен, воспользуйся подходящим пунктом меню `P`. Не используй force push без необходимости.

## 6. История

| Клавиши | Действие |
|---|---|
| `l` | Меню истории |
| `l l` | История текущей ветки |
| `l a` | История всех refs |
| `n` / `p` | Следующий / предыдущий коммит |
| `RET` | Просмотреть коммит и его diff |
| `q` | Вернуться назад |

## 7. Рабочий цикл с agent-shell

1. `C-x g` → `b b` → `develop` → `F u` — обновить базовую ветку.
2. `b c` — создать ветку задачи.
3. `C-c a` — запустить агента из рабочего проекта.
4. `get-current-task` → `plan-artifact` → согласование плана.
5. Реализация по чекпойнтам, `resume-record`, тесты.
6. `C-x g` → `g` → `TAB` — ревью изменений.
7. `s` — подготовить только проверенные изменения.
8. `c c` → сообщение → `C-c C-c` — коммит.
9. `P` — отправить ветку на нужный remote.
10. Создать Merge Request через GitLab в браузере.

## 8. Минимум для запоминания

```text
C-x g      Открыть Magit
g          Обновить статус
TAB        Раскрыть diff
b b        Переключить ветку
b c        Создать ветку
s / u      Stage / Unstage
c c        Начать коммит
C-c C-c    Подтвердить коммит
F / P      Pull / Push
l l        История
?          Меню команд
q          Назад
```

Если забыл конкретную команду, открой соответствующее Transient-меню (`b`, `c`, `d`, `l`, `f`, `F`, `P`) и посмотри доступные действия. Клавиши могут зависеть от версии Magit и пользовательских настроек.

Документация: https://docs.magit.vc/magit/
