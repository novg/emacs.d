# Окна, буферы и вкладки

Буфер — содержимое (файл, агент, Magit). Window — область отображения буфера. Tab Bar — конфигурация окон, не изоляция файлов или процессов.

| Клавиши | Действие |
|---|---|
| C-x b | Выбрать буфер через Consult |
| C-x 3 | Два окна рядом |
| C-x 2 | Два окна одно над другим |
| C-x o | Следующее окно |
| C-c w | Ace Window: выбрать окно |
| C-x 0 | Закрыть выбранное окно, не буфер |
| C-x 1 | Оставить только выбранное окно |
| C-c <left> | Winner: вернуть расположение окон |
| C-c <right> | Winner: повторить изменение расположения |
| C-x t 2 | Новая вкладка |
| C-x t o | Следующая вкладка |
| C-x t 0 | Закрыть вкладку |
| M-x tab-bar-rename-tab | Имя вкладки |
| C-x k | Закрыть буфер (не путать с окном) |

Упражнение: открой план, раздели окно C-x 3, во втором окне выбери agent-shell через C-x b. Переключайся C-c w. Нажми C-x 1, затем C-c <left> для восстановления.
Создай вторую вкладку для Magit или emacs.d, назови её и переключись обратно. Агент может продолжать работу при переключении вкладки. Закрытие вкладки не завершает сессию автоматически.

Начни с двух окон; вкладки используй только если удобно.
