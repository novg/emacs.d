# Agent-shell — памятка на каждый день

Для нашей конфигурации `novg/emacs.d` (Emacs 30+, Claude Code, Codex, Magit).

## 1. Основные клавиши

| Клавиши | Действие |
|---|---|
| `C-c a` | Открыть agent-shell, выбрать агента |
| `RET` | Отправить сообщение |
| `C-y` | Вставить текст |
| `M-p` / `M-n` | Предыдущее / следующее сообщение |
| `TAB` | Дополнение или раскрытие секции |
| `C-c C-c` | Прервать выполнение |
| `M->` | Перейти в конец буфера |
| `C-x b` | Переключить буфер |
| `C-x g` | Открыть Magit |

`C` — Ctrl, `M` — Alt, `RET` — Enter. Клавиши агента приведены для обычного shell-буфера, не viewport.

## 2. Рабочее пространство

Открой файл нужного проекта, затем `C-c a` и выбери Claude или Codex.

| Клавиши | Действие |
|---|---|
| `C-x 3` | Два окна рядом (код/план и агент) |
| `C-x 2` | Два окна одно над другим |
| `C-x o` | Перейти в другое окно |
| `C-x 1` | Оставить текущее окно |
| `C-x 0` | Закрыть текущее окно |

## 3. Передать контекст

Выдели фрагмент кода и выполни `M-x agent-shell-send-dwim RET`.
Можно также указать путь к файлу и номера строк прямо в сообщении агенту.
Перед внешним редактированием сохрани открытые файлы (`C-x C-s`).

## 4. Сессии

Команды вызываются через `M-x`:

| Команда | Действие |
|---|---|
| `agent-shell-new-shell` | Новая независимая сессия |
| `agent-shell-reload` | Перезапуск с прежним идентификатором сессии |
| `agent-shell-restart` | Перезапуск с чистым контекстом |
| `agent-shell-help-menu` | Меню доступных действий |

Восстановление контекста зависит от поддержки агентом и ACP-адаптером.

## 5. Настройки агента

Через заголовок буфера или `M-x`:

- `agent-shell-set-session-model` — модель.
- `agent-shell-set-session-mode` — режим работы и разрешений.
- `agent-shell-set-session-thought-level` — уровень рассуждений.
- `agent-shell-set-session-config-option` — дополнительные настройки.

Для планирования предпочитай режим с контролируемыми разрешениями.
Доступность команд и параметров зависит от версии пакета и агента.

## 6. Привычный рабочий процесс

1. `C-x g` — создать ветку задачи через Magit.
2. `C-c a` — запустить агента из проекта.
3. `/get-current-task` — получить информацию о задаче.
4. `/plan-artifact` — подготовить план реализации.
5. Открыть план рядом с агентом, обсудить и скорректировать.
6. Попросить реализовать план по чекпойнтам; использовать `resume-record`.
7. Проверить изменения через Magit, Diff-hl, Eglot и тесты.
8. Сделать коммит через Magit.

## 7. Если что-то не работает

- Не вставляется текст: `M->`, затем `C-y`; попробовать `M-x yank`.
- Агент завис: `M-x agent-shell-reload`.
- Нужен чистый контекст: `M-x agent-shell-restart`.
- Ошибка `Permission denied` при создании `.agent-shell`: запусти новую сессию из файла рабочего проекта, а не системного каталога.
- Не знаешь клавишу: `C-h k` и нужное сочетание; меню — `M-x agent-shell-help-menu`.
- Ошибка 404 при установке пакета MELPA: `M-x package-refresh-contents`, затем повторить установку.

История агента может содержать рабочие данные: не включай `.agent-shell/` в коммиты.

## Главное — семь сочетаний

```text
C-c a       Открыть агента
RET         Отправить сообщение
C-y         Вставить текст
C-c C-c     Остановить выполнение
C-x b       Переключить буфер
C-x o       Переключить окно
C-x g       Проверить изменения
```

Документация: https://github.com/xenodium/agent-shell

Памятка основана на нашем обсуждении; конкретные команды можно проверить через M-x в установленной версии. Расширенные возможности (viewport, очереди, параллельные агенты, fork) намеренно не включены.
