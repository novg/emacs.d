# C# — Eglot, Corfu и Cape

## Урок 1. Автодополнение
Открой .cs файл в проекте. В нашей конфигурации csharp-mode запускает Eglot с csharp-ls. Для работы сервера нужен установленный host toolchain.
Corfu показывает варианты после двух символов и паузы 200 мс. C-n/C-p или стрелки выбирают вариант; RET обычно принимает выбранный вариант, C-g закрывает список. M-x completion-at-point — ручной запрос дополнения.
Cape добавляет источники дополнения имён файлов и слов из буферов. Это дополнение к Eglot, а не отдельный языковой сервер.

## Урок 2. Навигация
| Команда | Действие |
|---|---|
| M-. | Перейти к определению (xref) |
| M-, | Вернуться |
| M-? | Найти ссылки на символ (xref) |
| M-x eglot-rename | Переименовать символ |
| M-x eglot-code-actions | Доступные действия сервера |
| M-x eglot-format-buffer | Форматирование, если сервер поддерживает |
| M-x flymake-show-buffer-diagnostics | Диагностика файла |
| M-x eldoc-doc-buffer | Документация символа |

Упражнение: открой вызов метода, перейди к определению и вернись. Найди ссылки на метод. Попробуй дополнение имени переменной в тестовой ветке.

## Урок 3. Проверка агентного кода
Diff-hl показывает изменения относительно Git; indent-bars — отступы; rainbow-delimiters и show-paren — вложенность и парные скобки. Electric Pair закрывает пары в программных буферах. C-x g открывает Magit для полноценного ревью. Auto Revert обновляет неизменённые файловые буферы после внешних правок.

## Если LSP не работает
M-: (executable-find "csharp-ls") — проверка пути.
M-x eglot — запуск; M-x eglot-reconnect — переподключение.
Проверь корень проекта и доступность .NET SDK. Возможности переименования и форматирования зависят от сервера. Не запускай массовые правки одновременно с пишущим агентом.
