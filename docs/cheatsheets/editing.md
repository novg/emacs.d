# Редактирование и рабочие пространства

Памятка для Emacs 30+ и конфигурации novg/emacs.d. C — Ctrl, M — Alt.

## Минимум для старта

| Клавиши | Действие |
|---|---|
| C-c j | Avy: ввести символы, затем метку для перехода |
| C-c e | Expand Region: расширить выделение; повторить для большего блока |
| C-c w | Ace Window: выбрать окно по метке |
| C-c u | Undo |
| C-c r | Redo |
| C-c h | Открыть памятку |
| C-c <left> | Winner: восстановить предыдущее расположение окон |
| C-c <right> | Winner: повторить изменение расположения |

## Markdown

Файлы .md и .markdown открываются в markdown-mode. TAB на заголовке позволяет переключать видимость раздела (в зависимости от контекста). C-c C-o — открыть ссылку, если соответствующая команда доступна в установленной версии. Для остальных действий используй M-x markdown- и подсказки Which-key. Планы и памятки можно редактировать рядом с agent-shell.

## Вкладки рабочих пространств

Tab Bar хранит разные конфигурации окон в пределах одного frame.

| Клавиши | Действие |
|---|---|
| C-x t 2 | Новая вкладка |
| C-x t o | Следующая вкладка |
| C-x t 0 | Закрыть вкладку |
| M-x tab-bar-rename-tab | Переименовать вкладку |

Например, одна вкладка для ADCS, другая для emacs.d. Вкладки не изолируют Git или процессы агентов. Закрытие вкладки не обязательно завершает агентную сессию.

## Поиск и массовое редактирование

1. C-c s r — Consult Ripgrep.
2. C-. — Embark, затем выбери действие Export (обычно E), чтобы получить grep-буфер.
3. M-x wgrep-change-to-wgrep-mode — сделать результаты редактируемыми.
4. Измени нужные строки.
5. C-c C-c — применить изменения; C-c C-k — отменить редактирование.
6. Проверь изменённые файлы, сохрани их при необходимости и просмотри diff через C-x g.

Не запускай одновременно агента, изменяющего те же файлы.

## Что работает автоматически

- Undo-fu-session: история отмены файлов между запусками, в ~/.cache/emacs/undo/. История может содержать фрагменты исходного кода; не публикуй её.
- Save Place: запоминает позицию в файле, в ~/.cache/emacs/places.
- Indent Bars: направляющие отступов в программных буферах.
- Rainbow Delimiters: разные цвета уровней вложенных скобок.
- Electric Pair: закрывает скобки и кавычки в программных буферах, не включается глобально.
- Show Paren: подсветка парных скобок.
- Pixel Scroll Precision: плавная прокрутка в графическом Emacs.
- Repeat Mode: после некоторых команд позволяет повторять их последней клавишей; ориентируйся на подсказку Emacs.

## Если клавиша не работает

C-h k и нужное сочетание покажут фактическую привязку в текущем буфере. Локальные карты major/minor modes могут переопределять глобальные клавиши.

При ошибке 404 от MELPA: M-x package-refresh-contents, затем перезапуск Emacs.

Начни с Avy, Expand Region, Ace Window и Undo/Redo. Остальное осваивай по необходимости.
