# Навигация и поиск — Vertico, Orderless, Consult, Marginalia, Embark

## Урок 1. Найти команду, файл или буфер
- M-x — команды. Введи `consult line`: Orderless ищет части имени независимо от порядка.
- C-x C-f — открыть файл. Для путей используется partial-completion, а не обычный Orderless.
- C-x p f — файл текущего проекта.
- C-x b — Consult Buffer: открытые буферы, недавние файлы и другие источники.
- C-n / C-p или стрелки — выбрать кандидата; RET — открыть; C-g — отменить.
- Vertico показывает список, Marginalia добавляет описания, Nerd Icons — значки.

Упражнение: открой init.el, README.md и эту памятку, затем переключайся между ними через C-x b.

## Урок 2. Найти код
| Клавиши | Действие |
|---|---|
| C-s | Consult Line — строки текущего буфера |
| C-c s r | Consult Ripgrep — содержимое файлов проекта (нужен rg) |
| C-c s f | Consult Find — поиск файлов |
| M-g i | Consult Imenu — классы, методы, заголовки (зависит от режима) |
| M-g g | Переход к номеру строки |
| M-g e | Ошибки компиляции |
| M-y | Выбор из kill-ring |
| C-c s h | История minibuffer (в подходящем контексте) |

Упражнение: в emacs.d найди все упоминания agent-shell через C-c s r, затем открой результат. В init.el найди строку use-package через C-s. Consult показывает предварительный просмотр; RET подтверждает переход, C-g отменяет его.

## Урок 3. Действия над результатом
C-. — Embark Act: открой меню действий над текущим кандидатом или объектом под курсором. Выбери нужную команду по показанному меню. C-; — Embark DWIM: действие по умолчанию (зависит от объекта).
Embark Consult добавляет интеграцию с результатами Consult. Для массовых изменений см. [editing.md](editing.md).

Не учи все действия Embark сразу. Начни с M-x, C-x b, C-s, C-c s r и C-. .
